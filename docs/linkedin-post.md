I just shipped a full-stack AI-powered sustainability platform from scratch.

EcoHabit is a campus circular economy app that helps college students buy, sell, donate, and recycle — while earning rewards for sustainable habits.

Here's what it includes:

AI Waste Scanner — snap a photo, TensorFlow classifies the waste in real-time
Flutter Mobile App — cross-platform, 288 tests, 0 analyzer issues
NestJS Backend — 196 tests, rate limiting, role-based admin access
Admin Dashboard — Next.js + Firebase auth for user/report/audit management
Gamification — daily quests, streaks, leaderboards, achievements
Multi-Campus — campus-specific features, settings, and data isolation

Tech stack:
Flutter · NestJS · TypeScript · Python · FastAPI · TensorFlow
Supabase · Firebase · Redis · Next.js · Tailwind CSS

By the numbers:
484 automated tests — 100% passing
11 milestones delivered across 3 phases
6+ technologies integrated end-to-end
3 apps built — mobile, admin dashboard, landing page

This project taught me full-stack development, AI/ML integration, system design, and shipping production-ready code.
