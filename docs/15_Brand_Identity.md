## 1. Brand Overview

### 1.1 Brand Mission

EcoHabit empowers college students to build sustainable habits through a circular economy platform that makes buying, selling, donating, and recycling effortless — while teaching entrepreneurship and environmental responsibility through gamified learning.

### 1.2 Target Audience

| Attribute | Detail |
|---|---|
| Age | 18–24 (college students) |
| Tech comfort | Digital natives, mobile-first |
| Values | Sustainability, affordability, community |
| Behavior | Active on social platforms, price-conscious, environmentally aware |

### 1.3 Brand Personality

| Trait | Description |
|---|---|
| **Friendly** | Approachable, warm, never condescending |
| **Sustainable** | Earth-conscious without being preachy |
| **Empowering** | Helps users feel capable and resourceful |
| **Playful** | Gamification makes sustainability fun |
| **Trustworthy** | Safe marketplace, reliable AI, transparent community |

### 1.4 Brand Voice

| Context | Tone | Example |
|---|---|---|
| Onboarding | Welcoming, encouraging | "Welcome to EcoHabit! Let's make a difference together." |
| AI Scanner | Confident, helpful | "This looks like a recyclable plastic bottle. Here's how to dispose of it properly." |
| Marketplace | Clear, trustworthy | "Listed 2 hours ago · Good condition · Price negotiable" |
| Gamification | Celebratory, motivating | "You just earned the Recycler badge! 5 more to go." |
| Errors | Calm, solution-oriented | "Something went wrong. Tap to retry." |

## 2. Logo

### 2.1 Logo Concept

The EcoHabit logo combines a leaf motif with a circular arrow, representing the circular economy cycle. The wordmark uses Inter Bold for clarity and modernity.

### 2.2 Logo Variants

| Variant | Usage | Minimum Size |
|---|---|---|
| Primary (icon + wordmark) | App icon splash, marketing, website header | 120px wide |
| Icon only | App icon, favicon, small contexts | 32px |
| Wordmark only | Text-heavy layouts, partnerships | 80px wide |

### 2.3 Clear Space

Maintain a minimum clear space around the logo equal to the height of the "H" in the wordmark on all sides.

### 2.4 Minimum Size

| Variant | Print | Digital |
|---|---|---|
| Primary | 30mm wide | 120px wide |
| Icon | 10mm | 32px |
| Wordmark | 20mm | 80px wide |

### 2.5 Logo Misuse

- Do not stretch or distort proportions
- Do not rotate the logo
- Do not apply drop shadows or effects
- Do not change the logo colors
- Do not place on busy backgrounds without sufficient contrast
- Do not crop any part of the logo

## 5. Visual Style

### 5.1 Design Philosophy

EcoHabit uses a **clean, modern aesthetic** with subtle depth. The design prioritizes readability, scannability, and touch-friendliness over visual complexity.

### 5.2 Border Radius

| Token | Value | Usage |
|---|---|---|
| `eco.radius.none` | 0 | No rounding |
| `eco.radius.xs` | 2px | Subtle rounding (chips) |
| `eco.radius.sm` | 4px | Small elements (tags) |
| `eco.radius.md` | 8px | Cards, buttons, inputs |
| `eco.radius.lg` | 12px | Bottom sheets, dialogs |
| `eco.radius.xl` | 16px | Large cards, modals |
| `eco.radius.2xl` | 24px | Feature cards |
| `eco.radius.full` | 999px | Circular (avatars, FABs) |

### 5.3 Elevation / Shadow

| Level | Light Mode | Dark Mode | Usage |
|---|---|---|---|
| 0 | None | None | Flat surfaces (background) |
| 1 | `0 1px 3px rgba(0,0,0,0.12)` | `0 1px 3px rgba(0,0,0,0.4)` | Cards at rest |
| 2 | `0 2px 6px rgba(0,0,0,0.15)` | `0 2px 6px rgba(0,0,0,0.5)` | Cards elevated, app bar |
| 3 | `0 4px 12px rgba(0,0,0,0.18)` | `0 4px 12px rgba(0,0,0,0.6)` | Dialogs, bottom sheets |
| 4 | `0 8px 24px rgba(0,0,0,0.22)` | `0 8px 24px rgba(0,0,0,0.7)` | FABs, floating elements |

### 5.4 Border Style

| Element | Width | Color | Style |
|---|---|---|---|
| Input field (rest) | 1px | `eco.neutral.300` | Solid |
| Input field (focus) | 2px | `eco.primary` | Solid |

## 8. Voice & Tone

### 8.1 Writing Principles

| Principle | Description |
|---|---|
| **Clear** | Use simple language, avoid jargon |
| **Concise** | Short sentences, scannable content |
| **Friendly** | Warm but not overly casual |
| **Helpful** | Guide users toward solutions |
| **Inclusive** | Gender-neutral, culturally aware |

### 8.2 Message Categories

| Category | Tone | Example |
|---|---|---|
| Success | Celebratory, brief | "Listing created!" |
| Error | Calm, actionable | "Upload failed. Check your connection and try again." |
| Empty state | Encouraging, guiding | "No listings yet. Start selling to earn your first badge!" |
| Loading | Reassuring | "Scanning your item..." |
| Notification | Informative, scannable | "New message from Rahul about the textbook" |
| Onboarding | Welcoming, step-by-step | "Step 2 of 4: Tell us about your campus" |

### 8.3 Error Message Guidelines

| Rule | Example |
|---|---|
| State what happened | "Your listing couldn't be posted" |
| Explain why (if known) | "The image is too large" |
| Offer a solution | "Try compressing the image or uploading a smaller file" |
| Avoid blame | ❌ "You uploaded an invalid file" |
| Use plain language | ❌ "HTTP 413 Payload Too Large" |
